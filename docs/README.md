## Dated evidence

[Pre-Loom QA](PRE_LOOM_QA.md), [production audit](PRODUCTION_AUDIT.md) and [final assessment audit](FINAL_AUDIT.md) retain their original test dates and qualifications. JSON receipts live in `evidence/`; screenshots live in `screenshots/`. A prior passing receipt does not establish the status of a later deployment.

[Planning](PLAN.md), [implementation milestones](IMPLEMENTATION.md) and [release history](RELEASE.md) are historical records. Read current guides for setup and operations. They are retained because they record decisions, real failures and verification provenance rather than duplicated current instructions.

The assessment PDF is retained as the supplied authority. Its redistribution permission and a project software license need owner confirmation; neither is implied by a public repository.
